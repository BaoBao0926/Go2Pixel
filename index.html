Go2Pixel: Grounding Navigation Goals to Image Pixels for Vision-Language Navigation

A pixel-based interface that turns high-level vision-language reasoning into navigable image goals.

Anonymous Author(s)

Abstract

Recent vision-language model (VLM) based methods for vision-and-language navigation in continuous environments (VLN-CE) commonly formulate navigation as low-level action prediction. However, this action-centric interface is often ambiguous, tied to short-horizon motion primitives, and inefficient due to repeated low-level querying. In this work, we propose Go2Pixel, a pixel-based paradigm that reformulates VLN-CE as navigable pixel grounding. Instead of predicting actions, Go2Pixel uses the image plane as a unified spatial interface between VLM reasoning and executable robot motion: the model outputs a navigable pixel coordinate, which is either back-projected into a 3D waypoint for forward navigation or interpreted through semantic padding regions for turning and stopping. To support long-horizon pixel grounding, we introduce a visibility-aware keyframe history representation that preserves compact navigation history images with trajectory overlays. To bridge the gap between pretrained VLM and pixel-space navigation, we further introduce lightweight adaptations, including visual semantic embeddings and coordinate-aware auxiliary losses, to improve the model's understanding of navigation-specific visual patterns and pixel-coordinate prediction. Experiments on R2R-CE and RxR-CE show that Go2Pixel achieves competitive navigation performance while substantially reducing VLM inference cost. On R2R-CE Val-Unseen, Go2Pixel achieves 54.1% SR and 52.5% SPL, while reducing average VLM calls from 46.62 to 7.75 compared with direct one-action prediction.

Contributions

  • We propose Go2Pixel, a pixel-based output interface that reformulates VLM-based VLN-CE from low-level action prediction into image-space goal grounding, providing an interface between VLM reasoning and executable motion.
  • We introduce ViKeyMem for compact visibility-aware history representation, together with lightweight VLM adaptations that improve pixel grounding.
  • Experiments on R2R-CE and RxR-CE show that Go2Pixel achieves competitive performance while substantially reducing VLM inference calls.
